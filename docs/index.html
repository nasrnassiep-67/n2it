N2IT Phone

A multi-tenant iOS softphone framework in SwiftUI, modelled on Acrobits Softphone. One app, many clients: each connects to <client>.voip.n2it.co.za.

Features

SIP callingRegistration, outgoing and incoming calls over UDP, TCP or TLS using the Linphone SDK.
Multi-tenantSign in with company code, extension and password. The PBX host is derived from the company code.
CallKitNative incoming-call screen, lock-screen answer, system audio handling.
Background callsPushKit VoIP push through a small Node gateway, so calls ring when the app is closed.
ContactsSearch and dial from the iPhone address book.
VoicemailMessage-waiting badge and one-tap voicemail dial.

How a background call works

  1. The PBX receives a call for an extension and notifies the push gateway.
  2. The gateway sends an APNs VoIP push to the phone.
  3. The app wakes and reports the call to CallKit immediately.
  4. The app re-registers with the PBX, which delivers the call.
  5. The user answers on the lock screen.

Build it

brew install xcodegen
cp Config/Secrets.example.xcconfig Config/Secrets.xcconfig   # optional dev defaults
xcodegen && open N2IT.xcodeproj

Requires a Mac with Xcode 15+ and a real iPhone (the simulator has no microphone).

Repository layout

N2IT/       SwiftUI app (SipManager, CallKitManager, PushManager, views)
gateway/    Node 18 APNs push gateway (no dependencies)
Config/     xcconfig templates (real secrets are gitignored)
project.yml XcodeGen project definition

Status

Early framework. It has not yet been compile-tested against the Linphone SDK. Voicemail message playback and PBX-side push hooks are still to do. See the README for open items.
