# iOS on the Mac: handover for Claude Code

Context for a Claude Code session on the owner's Mac. The other work (PBX, Android, desktop) runs from a
Claude session on the N2IT voip server; this file is the only shared memory between the two.

## The app
- Repo: github.com/nasrnassiep-67/n2it (the N2IT fork; Ebrahim's original repo is gone). iOS code: `N2IT/`,
  project generated by XcodeGen from `project.yml`. Bundle id `za.co.n2it.softphone`.
- Linphone SDK (linphonesw) + CallKit + PushKit. Push gateway in `gateway/` is not deployed yet, so with the app
  in the background iOS drops registration and incoming calls won't ring. Test calls with the app open.
- PBX: FusionPBX. Sign in with company code `n2it` (domain `n2it.voip.n2it.co.za`), an extension and its SIP
  password (FusionPBX > Accounts > Extensions). Owner is ext 1002. Transport TLS, port 5061.
- CI (`.github/workflows/ios.yml`) compiles unsigned on every push to main; the Ad Hoc job needs Apple secrets
  that are not set up.

## Recent work (merged to `main` 2026-10-06)
Adds "Add participant" + "Merge calls" (local Linphone conference) on Android, iOS and desktop.
iOS changes: `N2IT/SipManager.swift` (`addParticipant`, `merge`, conference-aware `hangupSip`, keeps CallKit up
while another call remains) and `N2IT/Views.swift` (person.badge.plus button, Merge/Complete transfer row).
Also on this branch for iOS: CallKit hold (`CXSetHeldCallAction` -> `SipManager.systemHold`), so "Hold & Accept"
for a GSM/WhatsApp call holds our call and resuming restarts audio. Not yet run on a real iPhone.
Test: PBX call, take a WhatsApp/GSM call with Hold & Accept (other side should hear hold music), end it, resume.

## Known issue to fix
`configure()` sets `core.mediaEncryptionMandatory = acc.srtp`; it should be `false` (optional SRTP), otherwise
calls to anything that doesn't offer SRTP fail.

## Steps on the Mac
1. Xcode installed and signed in with the N2IT Apple developer account (Xcode > Settings > Accounts).
2. `brew install xcodegen`
3. `git clone https://github.com/nasrnassiep-67/n2it && cd n2it && xcodegen generate`
4. Open `N2IT.xcodeproj`. Signing is preset in `project.yml` (team 69Y3USPRR5, automatic); check Signing &
   Capabilities shows that team with no errors.
5. Plug in the iPhone (Developer Mode on), run. Test: call 1002 <-> another extension, then Add participant,
   Merge calls, hang up.
6. Commit fixes on a branch (e.g. `ios-fixes`) and push; the voip-server session reviews and merges to main.

Rules: no secrets in the repo; do not change the PBX from the Mac (that is done from the voip server).
